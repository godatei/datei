Welcome to the Datei blog!

> **"Datei" is German for _file_.**
>
> But also for document. And dataset. Basically anything you really don't want
> to lose.

Datei is an open source, self-hosted file management platform. The source code
is available on [GitHub](https://github.com/godatei/datei).

## Do we need another document management solution?

Yes, I am using Google Drive for years and it doesn't make the cut anymore.
I want my personal documents to be organized and fully under my control.

I am using this blog post to share my vision for how we all should organize our documents
by announcing our initial values. I think code becomes cheaper every day, but our vision should get sharper the same way.

## Datei Core Values

### 1. Performance

Performance is a quality characteristic achieved by to technical excellence.
I don't want to use software that isn't efficient, takes too much memory or run loops that are not needed. It should always take the optimal path. Also a great design makes software fast, if its well designed you'll find the button faster, if this well build, you'll get the the response quicker.

Also performance is a compound result of choices and trade-offs. We picked the go programming language, a postgres database and an object storage.

But not only want to have a performant software, but also high speed releases, balzing fast community support.

### 2. Integrated

We all receive documents from various sources, Emails, Letters, Messages, Chats, Website Downloads.

We receive them on our laptops, mobile devices or just physically. All of these documents.

I want to support standarized formates like webdav so you can bring any client you want, but be flexible enough so datei can easily be plugged into your session.

### 3. Secure

Your documents need to be secure and safe. Protected from third party access. And accidental deletion.
We decided to not only store the latest version of your documents, but also keep a history of all versions using the Event sourcing pattern. This allows users to time travel to an exact date of their documents. This allows you to opt into more intellience features, more automation and more performance, because you know you can always revert _every_ step. Similar to how fast you can operate with code.

### 4. Intelligent

Why do we still use folders? Do we need to manully tag something? Why I can't search every document.

With Datei we give every document a markdown content, improve search and give your agents access to your documents. You might righly questio yourself if this doesn't transer all my documents to inferencing servers and you might be right at the moment, but with local models becoming more and more powerful, you'll be self sufficient quicker then you think.

### 5. Sustainable

We build in the open, we build to last. Yes, we are a VC and YC (S24) backed company. This is not the first product we are building. We sunsetted a [package manager for Kubernetes](https://github.com/glasskube/glasskube) and operating a [software distributino platform](https://github.com/distr-sh/distr) - which we can hopfully utilize to distribute Datei at a later date.

## Who is Datei for?

We want everyone to be able to self-host Datei to organize their documents.
If you feel comfortable with setting up or mantaining an infrastructure for your own documents,
you should be able to use Datei for free for your personal documents.
If you are part of this community, you will get the latest and greatest version of Datei
and hope you'll contribute feedback, spread the word and enjoy the experience.

So you can be part of a community.
